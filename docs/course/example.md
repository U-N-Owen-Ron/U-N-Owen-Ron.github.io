# 示例课程：Markdown 写作入门

> 本文是一篇示例文档，用来展示文章的标准写法。以后写新课程时，照着这个格式写即可。

## 文章信息

在文章开头用 `#` 写标题，然后可以直接写正文。常见的写作格式如下。

## 小标题

用 `##`、`###` 表示二级、三级小标题，层级越深数字越大。

## 列表

无序列表：

- 第一点
- 第二点

有序列表：

1. 第一步
2. 第二步

## 强调

**加粗文字**、*斜体文字*，以及 `行内代码`。

## 代码块

```python
print("Hello, w.paper!")
```
